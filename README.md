## 🚀 Quick Start & Run

### 1. Start the Backend API & Interactive Mobile Web App
```bash
cd "d:\vs projects\GharDekho\server"
npm install
npm start
```
Open **`http://localhost:4000`** in any browser.

---

## 🌟 Key Features in Slice 0
- **Two User Roles in One App:**
  - **Kirayedaar (Tenant):** Search rooms, filter by coaching/college/metro, view verified Jal timing, power backup, and live bed occupancy.
  - **Makan Maalik (Owner):** View dashboard, track active listings, post a new property via 4-step wizard, and receive tenant leads.
- **Split-Room Sharing Engine:** Live tracking of individual beds (e.g. "Room 204: 4 Beds, 2 Occupied, 2 Available") with immediate "Book Bed" reservation.
- **Indian Market Specifics:**
  - Water supply breakdown (24hr vs Jal Board timing alerts)
  - Power backup verification (Inverter vs 24hr Generator)
  - Bathroom configurations (Attached Western vs Common)
  - Tiffin service nearby indicator
  - WhatsApp direct connect button
- **Interactive Google Maps Mode:** Pinned verified listings with distance calculation.
